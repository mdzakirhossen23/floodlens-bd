AI model details

  • Model: Illustrative logistic flood scoring; separate unvalidated drought heuristic
  • Implementation: JavaScript scenario sandbox; Python historical-data model and evaluation published on GitHub
  • Features: Rainfall, river, soil, forecast, elevation, drainage
  • Explainability: Per-feature contribution ranking
  • Latency: local browser calculation; device-dependent, no validated latency claim

Data status & limitations

  • Current benchmark data is deterministic and synthetic.
  • No claim of operational forecasting accuracy is made.
  • 290 false positives out of 363 negative cases: specificity 20.11%. Balanced accuracy 58.44%; always-positive baseline accuracy 81.85%. Threshold calibration and independent data are needed.
  • Production use requires verified FFWC/BWDB/BMD observations.
